# reference/

Holds the frozen canonical *A. oryzae* RIB40 reference once Milestone 3 is
complete: genome FASTA, annotation, transcript FASTA, and the Salmon index.

Nothing goes here yet. Do not place files in this directory from unverified
sources; every file must be traceable to an authoritative accession (NCBI /
EnsemblFungi / FungiDB) with a recorded checksum in `config/reference.yaml`.
Large payloads under this directory are git-ignored by design (see
`.gitignore`) — only this README and directory structure are tracked.
